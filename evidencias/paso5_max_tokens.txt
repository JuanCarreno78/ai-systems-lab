Asistente: La arquitectura Transformer se compone de dos bloques principales: el **encoder** y el **decoder**, ambos compuestos por capas idénticas. El proceso comienza con la **embedding** de las palabras, que convierte tokens en vectores densos de dimensión fija. A estos embeddings se les añade el **positional encoding**, que agrega información sobre la posición de cada token en la secuencia, permitiendo al modelo captar relaciones de orden temporal.

En cada capa del encoder, se aplica **self-attention multi-cabeza**, donde múltiples cabezas de atención capturan diferentes aspectos de la relación entre tokens. Esto se logra mediante la multiplicación de matrices de peso, seguida de una suma y una activación. Después, se aplica una capa **feed-forward** (una red neuronal densa) para procesar cada token de forma independiente. Finalmente, se usa **normalización** (Layer Normalization) para estabilizar el entrenamiento.

El **decoder** sigue una estructura similar, pero incluye una atención **masked** para evitar que las posiciones futuras afecten la predicción. Además, el decoder recibe información del encoder mediante una atención cruzada, permitiendo al modelo comprender el contexto global de la secuencia de entrada.
